## Findings

### Bottom line

The five filings are enough for a credit snapshot of Vornado Realty L.P., but covenant levels, agency ratings, market prices and executed debt documents are missing, so creditors cannot yet judge covenant headroom, rating triggers or relative value.
Basis: 10-K_2025-12-31_vno-20251231.htm.jsonl, pages 78, 176, 179; 10-Q_2026-09-30_vno-20260930.htm.jsonl, pages 43, 77

The issuer is the operating partnership, which prints its own statements beside its parent trust's in each combined report with the same consolidated assets, so creditor analysis should rest on the partnership's statements and treat per-share and funds-from-operations measures as the trust's.
Basis: 10-Q_2026-09-30_vno-20260930.htm.jsonl, pages 3, 6, 11–13, 78

The latest report was signed 16 days before the as-of date, which falls 49 days after the balance-sheet date, so events after quarter-end sit outside every period statement, and covenant compliance is stated only as at year-end 2025.
Basis: calculation C-01; calculation C-02; 10-Q_2026-09-30_vno-20260930.htm.jsonl, pages 45, 85; 10-K_2025-12-31_vno-20251231.htm.jsonl, page 78
