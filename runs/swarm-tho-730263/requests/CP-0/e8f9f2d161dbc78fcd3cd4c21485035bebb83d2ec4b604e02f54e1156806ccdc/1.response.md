## Findings

### Bottom line

The four Thor Industries filings support a credit snapshot built on reported figures, but not covenant, guarantor, ratings or market-pricing conclusions, so creditors should treat any view on those points as unsupported by this evidence.
Basis: 10-K_2026-07-31_tho.htm.jsonl, page 87; 10-K_2026-07-31_tho.htm.jsonl, page 88; 10-K_2026-07-31_tho.htm.jsonl, page 93

The annual report for the year ended July 31, 2026, signed September 22, 2026, is the latest and controlling source, yet the run settings name the third quarter of 2026 as the current period, so the period behind every headline figure must be chosen and labelled before leverage or liquidity is called current. The filings print no adjusted EBITDA, so earnings capacity must be rebuilt from reported lines, and the short-term financial obligations on the balance sheet are not explained, which leaves the debt perimeter open. The executed credit agreements and the 2029 notes indenture are not supplied, so security and guarantor terms rest on the filings' own summaries.
Basis: 10-K_2026-07-31_tho.htm.jsonl, page 90; 10-Q_2026-04-30_tho.htm.jsonl, page 1; 10-K_2026-07-31_tho.htm.jsonl, page 93; 10-K_2026-07-31_tho.htm.jsonl, page 87
