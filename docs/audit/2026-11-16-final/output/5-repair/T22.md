## Parser mismatches

The historical review only named “two parser mismatches”; its underlying review files are unavailable. Recovery independently established these two concrete differences from source and tests:

1. The scorer accepts pipe rows without a Markdown separator; the general handoff renderer makes text blocks, so its previous first-table lookup offered no source control.
2. The scorer pools pipe rows across blank lines/prose until the next heading; the general parser ends the first table there. Showing only that first table omits accepted input rows and later qualifications.

The repair changes neither parser. The score-authoritative parser supplies accepted rows for presentation; the existing renderer still supplies original prose/citations and the Evidence address.
