- C5-011 (OQ-04, binding): `SourceFileLinks` is no longer drawn on Evidence > Sources, under an
  Evidence citation, or in the trace drawer, and the now unused component is deleted. The cited
  page range, which used to live only inside a link label, is kept as text (`Cited pages 2–3`)
  with its existing note on printed pages, through a new `citedSourcePages` in `sourceFiles.ts`

  `ReportContent.tsx` (not this task's file) still calls it to fill `trace.sourceLinks`.
- C5-009: list markers (`- ` only, not `* `, which can be a module's footnote marker) and code fence
  lines are removed from what is drawn; the text is otherwise exactly as written. A `- <name>
  <64-hex>` line is drawn as the name with the hash in `<code>` (mono), matching the Sources tab's
  rows in the same file. `SourceFileRow` was not used: it needs the library's `SourceFile` (kind,
  size, state, readers), which a handoff line does not carry, and inventing those would be a fake
  value. The forecast inputs keep their mono block, without the fence; the JSON is shown as written
  and not re-parsed or re-indented, so no number's form can change (J3-013's suggested change allows
  "a formatted code block without the backticks"). Handoff section names stay as the view's
  headings: the suggested change does not ask to remove them, the view exists to locate a handoff
  line, and the probe's `bareHeadings` (module codes) was already 0.
- C5-010: groups in the order High, Medium, Low, any other stated term (first seen first), then
  "Not recorded"; rows keep handoff order inside a group, and every row keeps its Severity cell,
  module and "Open source" link. Grouping matches the exact terms the Severity badge already
  accepts; it does not reinterpret other spellings.
- J3-007 (with C5-036): one line tells the reader how to choose something to trace. The handoff
  list stays on Trace (J3-007's suggestion "leave the downloads where they are"; removing it
  would be an R5 removal not covered by a ruling, and C5-036's other suggestion, a calculation
  register on Trace, is new content not asked by this task's ruling). The line names the control
