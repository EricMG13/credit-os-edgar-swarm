### The retry sentence (T04 reviewer's note)

I checked the service before keeping "Retrying Submit run is safe". `scheduler.submit` (`src/deploy_workflow/inbox/scheduler.py`, ~:299)
looks the submission id up in its records first and returns the existing record: "Repeating a submission returns its record".
So a repeat after a lost reply starts no second run, and the claim can be made. The text now is:

- request never arrived (browser TypeError): "The page lost contact with the service, so it cannot tell whether the run started.
  Submitting again is safe. The service starts one run for this approval and returns that run if it already exists."
- the service answered with another failure: "<Service message as a sentence>. The run may or may not have started.
  Submitting again is safe. The service starts one run for this approval and returns that run if it already exists."

No "try again" is repeated, and nothing claims the run did or did not start.
