Marker design (the shape the T33/S2-006 follow-up relies on):

- One 28 px footprint, the same `FOOTPRINT` classes as the control (including the 480 px tap area), so it goes wherever a control goes: in a header, a trailing slot, a `TableCard` `end` cell, a Timeline item slot. It needs no props beyond the ones a control takes: `<TraceControl trace={item.trace} label="Show sources for this date" />` with `trace` null or absent is enough.
- Dashed outline in the gap treatment (`border-dashed border-border-gap`, icon `text-gap-text`; 3.71:1 on white, 3.44:1 on canvas) and a file-with-a-cross icon (`FileX02`), so it differs from a control by shape as well as colour (D-39). On the navy band: dashed `border-white/50` (5.2:1) and `text-white/70` (9.6:1), with the same inverse focus ring.
- It is a `button` that is `aria-disabled="true"` and stays in the tab order. Name: the control's label plus `: no source recorded`, for example "Show sources for this finding: no source recorded". Tooltip on hover and keyboard focus: "No source recorded". It opens nothing. The accessible name keeps the "Show sources" prefix, which is what the S3-007 probe looks for.
- Touch: the tooltip does not open on tap, so a touch reader sees only the dashed icon, not the words.
