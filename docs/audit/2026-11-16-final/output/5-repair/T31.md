# T31 (group 3): Designed empty states on the shipped build

Base: `802f80d` (audit/repair-3, with T25, T26 and T30 merged). Implementer: repair-3 worker for T31.

## Findings

- S2-002 (Medium; merged S3-008 Medium, S4-013 Low, J6-013 Low, library half): on the shipped build
  (`web/dist/data.js` holds `issuers: []` and no library member) every library page drew a bare
  paragraph, "This data file holds no library pages", under its h1: no icon, no title, no next action,
  and a word ("data file") the reader never met. Ruling OQ-01 (R10): the static app is a design
  reference fed by saved samples, so the empty state must say that in the reader's words and offer a way
  forward.

Cause: `LibraryPage.tsx` drew its own `Notice` (a bare `<p>`) for the `absent` slice.

## Repair

- `web/src/pages/library/parts/LibraryPage.tsx`: the `absent` case now draws the page's h1 and a
  designed state from `Absent` (`parts/NotHeld.tsx`: featured icon, h2 title, one description and a
  "Back to the library" button). Title "No reports in this build"; description "This build is a design
  reference and holds no reports, so there is nothing to show at this address. Reports are written by
  runs on the run service." `LibraryPage` takes an optional `absent` node that replaces that state; the
  default serves History, Overview, Changes, Modules and every Evidence address. The `invalid` case keeps
  its `Notice`.
- `web/src/pages/library/Home.tsx`: passes its own `absent` state, the designed `NoRuns` state
  (title "No runs yet", "Start a run" button to `#/run/start`) with the design-reference sentence as its
  description: "This build is a design reference and holds no reports. Reports are written by runs on the
  run service; start one to add the first issuer." `NoRuns` now takes its description, so the loaded-but-no-cards
  state keeps its text (`NO_RUNS`) and the absent state has `NO_LIBRARY`. A "Back to the library" link on
  the home itself would point at the page it is on, so the home takes the `Start a run` action the
  designed empty state already had (D-31 Pass example).

Wording: "design reference" and "run service" are the terms T25's callout already uses on every sample
page; "data file" and "library pages" are gone (CM-019, D-01, D-16). Nothing on the page names a file,
slice or fixture.
