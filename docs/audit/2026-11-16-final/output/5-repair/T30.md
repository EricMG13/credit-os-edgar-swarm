# T30 (group 3): Focus after Clear filters and Show all

Base: `0143a3e` (audit/repair-3, with T26 merged). Implementer: repair-3 worker for T30.

## Findings

- S1-006 (Medium; merged S2-014, Low): pressing "Clear filters" in the library home's no-match state
  removed the focused button and left focus on the document body.
- S4-005 (Medium): activating "Show all items" (Trace) or "Show all files" (Sources) in the empty state
  sent focus to the document body.

Cause: each way-back button sits inside the empty state it clears. Pressing it clears the filter state,
the empty state unmounts with the button, and nothing named a place for the focus to go (D-38: if the
opener has gone, focus goes to a logical place).

## Repair

- `web/src/pages/library/parts/ModuleFilter.tsx`: `useModuleFilter` keeps a ref on a `display: contents`
  wrapper around the Module filter's control, and its `clear` now also focuses the control's trigger
  button. `clear` is the one function every empty state's way back runs, so Trace ("Show all items"),
  Sources ("Show all files") and Gaps ("Show all gaps", the same cause, not named in S4-005) are all fixed
  at the cause. `EvidenceTrace.tsx` and `EvidenceSources.tsx` needed no change: both receive `onClear`
  from this hook.
- `web/src/pages/library/Home.tsx`: `Layout` keeps a ref on a `display: contents` wrapper around
  `FilterBar`, and its `clear` also focuses the bar's first input, the search field ("Search issuers").
  Both layouts (cards and list) draw `NoMatch` with this `clear`.

The wrappers have no box, so layout is unchanged. `FilterBar` and `FilterSelect` (`parts/FilterBar.tsx`,
not in T30's files) take no ref, so the wrapper plus a `querySelector` stands in for a `ref` prop on them.

## Tests (failing first, then passing)

- `web/src/pages/library/Home.clearFocus.test.tsx` (new): search "zzz" shows "No issuer matches"; focus
  "Clear filters", activate it; expects the filters cleared and `document.activeElement` to be the
  "Search issuers" box. Once in the cards layout, once in the list layout.
- `web/src/pages/library/parts/ModuleFilter.clearFocus.test.tsx` (new): on the Trace, Sources and Gaps
