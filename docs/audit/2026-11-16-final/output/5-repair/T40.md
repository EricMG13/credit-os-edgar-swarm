## Not verified

1. The drawer is thin by necessity. The Model slice delivers an address into the run's Evidence and no trace
   content, so the drawer shows the item's name, a fixed sentence ("The sources for this item are listed on the
   run's Evidence page."), an "Item" row and "Open in Evidence". CM-008's "lists the Basis items with source,
   page, quoted passage and calculation steps" cannot be met until the slice (`slice/read.ts`, `types.ts`,
   `fixtures/model.json`, delivery) carries trace content; those files are outside T40. In the static fixture the
   run's Evidence page does not exist in the library fixture either (S5-003, OQ-01), so "Open in Evidence" still
   ends in "No such issuer" there.
2. The control stays a link (role link, `href`, `aria-haspopup="dialog"`) rather than becoming a button: 45
   assertions in eight existing test files (and `p-trace-nav.mjs`) locate it by link role and check its `href`,
   and a link keeps Ctrl-click and copy-address working. A button, as in the library, would be the tidier role.
3. `PressTip` lives in `StatementTable.tsx` and `MetricTile.tsx` imports it, to stay inside the task's files; its own
   file would be tidier.
4. No real touch device or screen reader: touch was emulated (Playwright `hasTouch`, jsdom pointer events). The
   info button is still 16 px; its target size is not part of S5-008. A tooltip opened by a tap is closed by a
   second tap, a press elsewhere, Escape or blur.
5. Ctrl-, Meta- and Shift-click were tested in jsdom only (no drawer), not in Chromium.
6. S5-005 was measured at 390 px only (not 320 or 200 percent text); from `sm` up the layout is unchanged.
7. The reason of an unreadable run is logged only on that run's page; an unnamed unreadable run has no page and
   no log, as before. Two unreadable runs of one issuer look identical in the list.
8. Every existing test that makes a slice unreadable now prints one `console.warn` line (only `RunPage.test.tsx` silences it).
9. Not run: the full suite, `npm --prefix web run gates`, `proof:connected`, `test:file:gates`, the other S5 probes.
