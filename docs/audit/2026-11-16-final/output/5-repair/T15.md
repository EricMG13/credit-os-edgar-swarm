## Decisions

- **Where a tile's trace comes from.** The catalogue metric carries a `source` id, but `Snapshot.catalogue` is typed without it and the type lives in `publishedReport.ts`, which is not in this task's file list. The row is therefore found in the CP-1 handoff the Overview already holds (`view.entries`): `headlineSources` looks in the `Chart data: <chart>` table for the row whose Period is the figure's period, and only accepts it when the figure's column in that row holds exactly the catalogue's value. The chart and column heading per metric mirror `_METRICS` of `credit_os_catalogue.py` (a heading is matched by its words, so the adjusted twin is read the same). A figure whose row is not found, or states another value, or whose heading matches two columns, gets no control rather than one that disagrees with its tile. The Python builder guarantees the same text, so on a run the service built this does not occur; it is a guard, covered by `reportView.headline.test.ts`.
- **One control per tile, opened by the existing mechanism.** `PublishedSource` (as the module pages and Changes use): a button `Show sources for <figure>` that opens the same drawer inside the report's `PublishedTraceProvider`, so Show sources, hover, focus return and "Open in Evidence" behave as elsewhere. The drawer is the chart row's, as on the module page ("Sources for Chart data: leverage"), not a per-cell drawer; a per-cell trace is the separate J3-003 remark that the drawer gives the table caption, and was not asked for here.
- **A gap, not a note.** The finding allowed a gap tile or a one-line note. A tile was chosen because the component map (stat tile with a missing figure) and CM-023 say `n.a.` in place of the figure with its reason, and a tile keeps the figure's place and its trace. The tile reads `n.a.` (the design system's `Missing`), then the module's own words when the handoff row says `Not supplied: ...` (drawn through `readerText`, no analysis added), the period, and a control to that row. Where the handoff row cannot be read (the library card holds no handoff; a row the module did not mark "Not supplied"), the tile reads `n.a.` and `Not supplied`, with no control.
- **Which absent figures get a tile.** Every one of the six listed headline figures the catalogue does not carry, but only while at least one of the six is supplied; a catalogue with none draws nothing, as before (the whole headline block is then a different state, which the module pages state). This also closes C1-009 on the library card, which has only the catalogue. The "Undrawn facilities" card stays out (CM-044).
- **Gap period.** A figure the catalogue lacks has no period of its own; the row looked up is the one at the period of the first supplied figure. If a chart's rows do not carry that period, the tile still states the gap, without reason or control.
- **Empty string is missing; zero is a figure.** `stated()` is `value != null && value !== ""`, so `"0"` still draws `$0m` and `""` draws the gap instead of a label with no value (C1-009).
- **No change outside the three files.** `LibraryIndex.tsx` is untouched: it passes only the catalogue, so its card gets the gap tile and no control, which is what the catalogue alone can support.
- **Fidelity (draft for VERIFICATION.md, scope: Overview headline tiles and library card headline tiles, synthetic Northbridge run, canned CP-1).** Values, periods and units on screen before and after are identical for the five supplied figures (probe tile texts: `Net leverage2.25x-0.75x vs FY2023betterFY2024`, `Gross leverage2.80x-0.95x vs FY2023betterFY2024`, `Interest coverage4.00x+0.80x vs FY2023betterFY2024`, `Revenue$2,250m+$150m vs FY2023betterFY2024`, `Cash$275m-$25m vs FY2023FY2024`); the sixth tile now states Adjusted EBITDA FY2024 as not supplied, in the module's words, as `proof/handoffs/CP-1.md:127` says it. The main-path tiles (`MetricGrid`, drawn when the handoff has a `Financials and credit metrics` table) were not changed and not exercised on a retained run.
