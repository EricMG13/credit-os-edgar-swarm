# T11: Review sheet, long names at 390 px; decisions that block Submit first

BASE: `e574f0d746f6db9e0501d082b9dfc28d5448eed6` (`audit/repair-1` at the start of the task).
Findings: C2-001 (Medium), C2-007 (Medium). Role: implementer. C2 probe port: 8751.

## Cause

- C2-001: the review blocks are CSS grids with an implicit `auto` track and no wrapping rule, so an
  unbroken file or issuer name sets the track's minimum width. The content grows past the 316 px
  column and clips every Edit button and the Submit button. The Documents step already avoids
  this with `min-w-0` and `wrap-anywhere`.
- C2-007: `ReviewSheet` drew `LimitsToDecide` after the "What will run" section, so the decisions
  that block Submit sat after 2,700 px (3,600 px at 390 px) of echoed inputs.

## Change (one file, `web/src/pages/connected/start/ReviewSheet.tsx`)

- `LimitsToDecide` is drawn first in the fragment, directly under the "Review and start" heading
  and its intro line; "What will run" follows. Nothing is removed, folded or reworded: every
  block, row and "Not given" line is still drawn. (The finding's optional suggestion to fold the
  "Not given" blocks into one line or a closed disclosure is not made: it removes rows the reader
  sees today, R5, and the task says to keep every row.)
- `wrap-anywhere` on the two `<section>` elements ("What will run", "Limits to decide"), so all
  text inside them wraps at any character when it has no space (`overflow-wrap` is inherited), and
  `min-w-0` on those two sections and on the `Block` container (the grid items), as the Documents
  list does. The Button already has `whitespace-nowrap`, so the Edit and Leave out buttons do not
  break inside a word.
- Approval checkbox, blocker line, Submit button, `onAccept`, `onEdit`, `onModules` and the
  disabled logic are untouched (they live in `StartRun.tsx`, not changed).

## Round 2 (review findings R1 and R2)

BASE for this round: `bc1b19b263ac5958d467582a63b11a4454d47c27` (round 1's commit). Reviewer: `T11-review.md`
(uncommitted, not edited). Files changed in this round: `web/src/pages/connected/start/ReviewSheet.tsx`
(three lines) and `ReviewSheet.test.tsx` (two tests added). R3 and R4 are Low and need no change here.

### Cause

- R1 (regression of round 1): `wrap-anywhere` on the "What will run" section is inherited by each block's
  `h4`. The `h4` shares a non-wrapping flex row with the `whitespace-nowrap` Edit button, and `anywhere`
  lowers the title's minimum width, so the row squeezed the title to a sliver and split it inside a word
  ("docume / nts" at 390 px, six lines at 360 px).
- R2 (not in the register; closed here as a review finding): the Leave out button is `whitespace-nowrap`
  (base Button), so its label ("Leave out Legal & covenants and Recovery & fulcrum", 380 px) set the minimum
  width of the card's grid track. On the Deep pathway with no agreement the Limits to decide card was 408 px
  in a 316 px column. Round 1's note that the nowrap Button keeps the Edit and Leave out buttons from
  breaking was the cause, not a remedy, for the Leave out button.

### Change

- `Block` header row: `flex items-center justify-between gap-3` becomes `flex flex-wrap items-center
  justify-between gap-3`. When the title and the Edit button do not fit on one line the button drops below the
  title, so the title is never the item that is squeezed. The `h4` keeps the inherited `wrap-anywhere` (no
  `wrap-normal`): alone on its line it breaks between words, and inside a word only if one token is wider than
  the whole line, so a long unbroken name is still contained (C2-001 stays fixed).
- Leave out `Button`: `className="max-w-full text-left whitespace-normal"`, the form StartRun.tsx:2424 uses.
  Label, action (`choice.onModules(kept)`), position and the explanatory paragraph are unchanged.
