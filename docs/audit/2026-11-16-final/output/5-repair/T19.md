## Decisions

- **One drawing, not two (C4-004 and X1-024 together).** The cause of both is that `StackChart` refused any part that was not above zero, so `charts.tsx` kept a second hand-built bar for stacks with a zero or an unstated balance, which had no key. `StackPart.value` is now `number | null`: above zero draws a segment; zero or null is a legend row with no segment. The connected `stack()` passes every facility, in rank order, to `StackChart` (as the finding suggested: stated parts to the stack, the unstated facility as a row). The 35-line fallback is deleted. Connected `stack()` still returns null when no facility has a balance above zero, and when a name repeats or a value is negative, exactly as before.
- **No swatch on a row without a segment.** A swatch ties a colour to a segment; a zero or unstated facility has none, so its row has an empty cell of the swatch's width (alignment kept) and shows its amount (`0`, in the primary colour) or the source's own words (`Not supplied: balance not stated`, in the tertiary colour, D-14). Colours still follow rank, so a facility keeps its colour whether or not an earlier facility is drawn.
- **Round end on the last drawn segment**, not on the last part: with the fixture's last part at 0, the last drawn segment would otherwise be square-ended.
- **Reader: `>= 0`**, message `expected a number of zero or more` (the wording the other readers use for a negative); a negative part is still unreadable. An all-zero static stack reads and draws the legend alone (checked in a browser at 1200 px and in jsdom); the connected path draws no stack for it, unchanged.
- **X1-019 by room, not by clamping.** `BarCanvas` takes `extraTop` (default 0, so the waterfall is unchanged); `ColumnsChart` passes the 16 px raise when there are three or more series. Clamping the label to the first line inside the drawing would put the raised middle label level with its neighbours' labels, which is what the raise exists to avoid. The plot is 16 px shorter for three or more series.
- Fidelity: no value, period, unit or text is changed. The connected Debt stack shows the same facility names, amounts and source words in the same order; it gains the key, the keyboard readout (the svg `application` and its readout) and the Table form it already had. The hover `title` and per-segment `role=img` name of the removed hand-built bar are replaced by the legend and the Table form (D-28).
